# Activité de publication de Workfront Fusion : semaine du 7 septembre 2026

Cette page décrit toutes les améliorations apportées à Adobe Workfront Fusion au cours de la semaine du 7 septembre 2026.

Pour obtenir la liste de toutes les modifications récentes, voir [Activité de publication d’Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Pour obtenir la liste des correctifs récents dans Workfront Fusion, reportez-vous à la page [Mises à jour de maintenance Workfront](https://experienceleague.adobe.com/fr/docs/workfront-known-issues/releases/current-updates) et recherchez toutes les mises à jour intitulées Mise à jour de maintenance de Workfront Fusion.

## Nouveaux types d’autorisations pour les Webhooks personnalisés

Vous pouvez désormais autoriser les Webhooks personnalisés à l’aide de deux nouvelles méthodes : authentification par clé API et signature HMAC. L’authentification de la clé API est désormais le type d’autorisation par défaut pour les nouveaux Webhooks. Les types d’autorisation précédents sont toujours disponibles et vous pouvez sélectionner la valeur vide pour aucune autorisation.

Pour plus d’informations, voir [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).

## Nouveau bouton Décrire avec l’IA dans la description du scénario

Vous pouvez désormais cliquer sur Décrire avec l’IA dans le champ de description du panneau Paramètres d’un scénario pour que l’IA génère automatiquement une description du scénario, en fonction des modules et de la configuration du scénario.

Pour plus d’informations, voir [Configurer les paramètres de scénario](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description).

## Connecteur MCP Fusion AEM

Envoyez une invite en anglais clair à votre propre serveur MCP (Model Context Protocol) Adobe Experience Manager et laissez un modèle d’IA décider des actions Adobe Experience Manager nécessaires pour l’exécuter. Ce nouveau connecteur dédié ajoute un seul module, Traiter une invite utilisateur, qui :

* Se connecte à Adobe Experience Manager à l’aide d’OAuth - aucune information d’identification manuelle requise.
* Interprète vos instructions et appelle les actions Adobe Experience Manager nécessaires (sites, ressources, fragments de contenu, dossiers, référentiel de contenu et IA dédiée au contenu) pour y répondre.
* Permet de restreindre les actions en lecture seule et en écriture/suppression que l’IA est autorisée à effectuer, de sorte que même un scénario sans assistance ne puisse pas effectuer d’action destructive inattendue.
* Utilise par défaut son propre service d’IA ou votre propre clé OpenAI, Anthropic Claude ou Amazon Bedrock si vous préférez.

Pour plus d’informations, voir [Modules MCP &#x200B;](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/aem-mcp-modules.md).

## Nouveau module Scénarios d’exportation dans le connecteur Workfront Fusion

Le connecteur Workfront Fusion comprend désormais un module Exporter les scénarios , qui vous permet d’exporter le plan directeur d’un ou de plusieurs scénarios directement depuis un scénario.

Pour plus d’informations, voir [Modules Workfront Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## Définition de jetons personnalisés dans les modules de déclenchement instantané Workfront et Workfront Planning

Pour rendre vos Webhooks Workfront plus flexibles et plus sécurisés, nous avons créé la possibilité d’ajouter des jetons personnalisés. Désormais, vous pouvez fournir votre propre valeur de jeton pour sécuriser les webhooks dans le module Workfront > [!UICONTROL Événements Espion] et le module Workfront Planning > [!UICONTROL Événements Espion (V2)]. Auparavant, Fusion générait toujours ce jeton automatiquement. Si vous laissez le nouveau champ [!UICONTROL Jeton personnalisé] vide, Fusion continue à générer le jeton pour vous.

Pour plus d’informations, voir [Modules Workfront et leurs fonctions](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-modules.md) et [Modules Workfront Planning et leurs fonctions](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-planning-modules.md).
