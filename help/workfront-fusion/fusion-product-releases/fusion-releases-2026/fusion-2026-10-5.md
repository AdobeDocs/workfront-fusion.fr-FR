# Activité de publication de Workfront Fusion : semaine du 5 octobre 2026

Cette page décrit toutes les améliorations apportées à Adobe Workfront Fusion au cours de la semaine du 5 octobre 2026.

Pour obtenir la liste de toutes les modifications récentes, voir [Activité de publication d’Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Pour obtenir la liste des correctifs récents dans Workfront Fusion, reportez-vous à la page [Mises à jour de maintenance Workfront](https://experienceleague.adobe.com/fr/docs/workfront-known-issues/releases/current-updates) et recherchez toutes les mises à jour intitulées Mise à jour de maintenance de Workfront Fusion.

## Connecteur Jira : nouveaux types de connexion de compte de service

Pour faciliter la création de connexions Jira correspondant à la manière dont votre équipe s’authentifie, nous avons ajouté deux nouveaux types de connexion au connecteur Jira : Jeton API du compte de service et Compte de service OAuth 2.

Ces options vous permettent de créer des connexions pour l’automatisation qui doivent s’exécuter en tant que compte de service Jira dédié au lieu de compte d’utilisateur personnel. Utilisez le jeton API du compte de service lorsque votre compte de service Jira s’authentifie avec un jeton API et utilisez le compte de service OAuth 2 lorsque votre environnement utilise OAuth 2 pour le compte de service.

Les types de connexion de base et OAuth2 sont toujours disponibles.

Pour plus d’informations, voir [Modules Jira](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md).

## Nouveau module Créer plusieurs annotations disponible pour le connecteur Veeva Vault

Pour faciliter l’utilisation du module Créer plusieurs annotations , nous l’avons mis à jour vers un nouveau module. Vous pouvez désormais sélectionner des champs pour les repères, les références et d’autres champs d’annotation avant de fournir des valeurs, ce qui facilite la configuration et se concentre uniquement sur les valeurs que vous priorisez.

Le module Créer plusieurs annotations , auparavant disponible, est toujours marqué comme « Hérité ».

Pour plus d&#39;informations sur les modules Veeva Vault, voir [Modules Veeva Vault](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md).
