# Activité de publication de Workfront Fusion : semaine du 23 novembre 2026

Cette page décrit toutes les améliorations apportées à Adobe Workfront Fusion au cours de la semaine du 23 novembre 2026.

Pour obtenir la liste de toutes les modifications récentes, voir [Activité de publication d’Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Pour obtenir la liste des correctifs récents dans Workfront Fusion, reportez-vous à la page [Mises à jour de maintenance Workfront](https://experienceleague.adobe.com/fr/docs/workfront-known-issues/releases/current-updates) et recherchez toutes les mises à jour intitulées Mise à jour de maintenance de Workfront Fusion.

## Rôles d’équipe personnalisables

Chaque équipe dispose désormais d’un onglet **Rôles** dans lequel vous pouvez créer, mettre à jour et supprimer vos propres rôles et choisir exactement les autorisations incluses par chaque rôle. Vous n’êtes plus limité à un ensemble fixe de rôles. Grâce aux rôles personnalisés, vous pouvez accorder à chaque personne uniquement l’accès dont elle a besoin pour sa tâche, configurer l’accès en fonction du fonctionnement de votre entreprise et gérer l’accès vous-même sans avoir à contacter l’assistance.

Pour plus d&#39;informations, voir [Afficher et gérer les rôles d&#39;équipe](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/manage-users-and-teams/view-and-manage-team-roles.md).

## Nouveau module Enregistrements Watch dans le connecteur Workfront Fusion

Le connecteur Workfront Fusion comporte un nouveau module de déclenchement **Enregistrements de contrôle**. Utilisez-le pour suivre ce qui se passe dans Fusion sans vérifier manuellement. Le module peut surveiller les nouveaux enregistrements, les mises à jour des enregistrements existants ou les deux, et vous pouvez utiliser des filtres pour vous concentrer sur les modifications qui comptent pour votre équipe.

Pour plus d’informations, voir [Modules Workfront Fusion](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## Préférences MCP pour les organisations

Les propriétaires et les administrateurs d’entreprise peuvent désormais choisir les outils de MCP de Fusion disponibles pour leur entreprise. Dans les détails de l’organisation, sous **Préférences MCP**, vous pouvez autoriser ou désactiver les outils en lecture seule et les outils d’écriture. Les outils d’écriture nécessitent des outils en lecture seule pour être activés.

Le paramètre s’applique à l’ensemble de l’organisation. Les outils désactivés n’apparaissent pas dans la liste d’outils et Fusion les rejette si un agent les appelle. Le paramètre limite uniquement les appels d’outil effectués via le serveur MCP Fusion officiel. Les actions que les utilisateurs effectuent dans l’interface utilisateur de Fusion, par le biais de l’API ou d’autres intégrations sont toujours contrôlées par les propres autorisations de chaque utilisateur dans Fusion.

Pour plus d&#39;informations, consultez [Gérer les préférences MCP pour votre organisation](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/configure-fusion-mcp-server.md#manage-mcp-preferences-for-your-organization).
