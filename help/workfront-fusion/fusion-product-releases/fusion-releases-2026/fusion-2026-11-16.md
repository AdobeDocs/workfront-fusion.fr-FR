# Activité de publication de Workfront Fusion : semaine du 16 novembre 2026

Cette page décrit toutes les améliorations apportées à Adobe Workfront Fusion au cours de la semaine du 16 novembre 2026.

Pour obtenir la liste de toutes les modifications récentes, voir [Activité de publication d’Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Pour obtenir la liste des correctifs récents dans Workfront Fusion, reportez-vous à la page [Mises à jour de maintenance Workfront](https://experienceleague.adobe.com/fr/docs/workfront-known-issues/releases/current-updates) et recherchez toutes les mises à jour intitulées Mise à jour de maintenance de Workfront Fusion.

## Améliorations de l’interface utilisateur de la file d’attente Webhook

La page de la file d’attente webhook possède une nouvelle disposition correspondant aux listes de scénarios et de Webhooks. Il est donc plus facile de rechercher et de gérer les événements placés dans la file d’attente. Vous pouvez maintenant effectuer les opérations suivantes :

* **Rechercher :** filtrer les événements chargés dans la file d’attente.
* **Trier :** Trier les événements par identifiant, date de création ou taille.
* **Naviguer :** modifier la taille de la page, passer d’une page à l’autre et charger des événements supplémentaires.
* **Afficher les détails :** ouvrez la payload d’un événement dans la boîte de dialogue Détails mis à jour.
* **Sélectionner et supprimer :** Sélectionnez des événements individuels ou utilisez Sélectionner tout pour sélectionner la file d’attente entière, avec des exclusions facultatives. La suppression de tous les événements vide la file d’attente. Il ne supprime pas le webhook.

Pour plus d’informations, voir [Afficher la file d’attente d’un webhook](/help/workfront-fusion/manage-scenarios/view-webhook-queue.md).


## Stockage Adobe : télécharger un module de fichier

Le connecteur de stockage Adobe comporte un nouveau module **Charger un fichier**. Le module gère le chargement complet en une seule étape. Il crée le fichier de destination, initialise le chargement, transfère le contenu du fichier par le biais d’une URL présignée et finalise le chargement, de sorte que vous n’avez plus besoin de configurer des étapes de transfert et de finalisation distinctes. Le module prend en charge les fichiers volumineux.

Pour plus d’informations, voir [Modules de stockage Adobe](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-storage-modules.md).
