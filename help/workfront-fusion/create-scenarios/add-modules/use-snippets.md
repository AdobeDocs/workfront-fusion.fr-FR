# Enregistrer et réutiliser des sections de scénario avec des fragments de code

>[!NOTE]
>
>Cette fonctionnalité n’est disponible que dans la nouvelle expérience de l’éditeur de scénarios. Pour plus d’informations, voir [Expériences nouvelles et classiques](/help/workfront-fusion/get-started-with-fusion/navigate-fusion/scenario-editor.md#new-and-classic-experiences) dans l’éditeur de scénarios d’article.

Un extrait de code est un groupe de modules que vous enregistrez en tant qu’unité. Vous pouvez ajouter un fragment de code à d’autres scénarios, de sorte que vous n’ayez pas à créer la même section d’un scénario plusieurs fois.

Le panneau Fragments de code vous permet de rechercher, baliser, prévisualiser, épingler et trier des fragments de code, de les faire glisser et de les déposer dans un scénario, de les importer et de les exporter, et de les partager avec des équipes ou des organisations, ou d’en envoyer une copie à un autre utilisateur.

## Création d’un fragment de code

1. Cliquez sur l’onglet **[!UICONTROL Scénarios]** dans le panneau de gauche.
1. Sélectionnez le scénario qui contient les modules que vous souhaitez enregistrer.
1. Cliquez n’importe où sur le scénario pour accéder à l’éditeur de scénarios.
1. Maj+clic sur les modules que vous souhaitez inclure dans le fragment de code.
1. Cliquez avec le bouton droit sur l’un des modules sélectionnés, puis sélectionnez Créer un fragment de code.
1. Saisissez un nom pour le fragment de code.
1. Cliquer sur **Enregistrer**.

## Ajouter un fragment de code à un scénario

1. Cliquez sur l’onglet **[!UICONTROL Scénarios]** dans le panneau de gauche.
1. Sélectionnez le scénario dans lequel vous souhaitez ajouter un fragment de code.
1. Cliquez n’importe où sur le scénario pour accéder à l’éditeur de scénarios.
1. Cliquez sur l’icône **Fragments de code** ![Fragments de code](assets/snippets-icon.png) dans la zone Contrôles.

   Vous devrez peut-être cliquer sur l&#39;icône des trois points dans la zone Contrôles pour afficher l&#39;icône Fragments de code.

1. (Facultatif) Sélectionnez un fragment de code pour le prévisualiser.
1. Cliquez sur le fragment de code pour l’ajouter à l’éditeur.
1. Connectez le fragment de code à votre scénario.
1. Mettez à jour les champs du fragment de code pour qu’ils fonctionnent avec le scénario auquel il a été ajouté.

## Organisation des fragments de code

Dans le panneau Fragments de code, vous pouvez :

* Recherchez un fragment de code.
* Épingler les fragments de code que vous utilisez souvent.
* Exportez un fragment de code sous la forme d’un fichier JSON.
* Partagez des fragments de code avec d’autres organisations, équipes ou utilisateurs.
* Prévisualisez un fragment de code avant de l’ajouter à un scénario.
* Triez la liste des fragments de code.

## Partage d’un fragment de code

Vous pouvez partager un fragment de code avec une équipe ou une organisation, ou en envoyer une copie directement à un autre utilisateur.

Vous pouvez :

* **Partager avec une équipe ou une organisation** : partagez le fragment de code afin que d’autres membres puissent l’utiliser.
* **Envoyer une copie à un utilisateur** : envoyez une copie à un utilisateur. L’utilisateur reçoit sa propre copie.


1. Cliquez sur l’icône **Fragments de code** ![Fragments de code](assets/snippets-icon.png) dans la zone Contrôles.
1. Pointez sur le fragment de code à partager, puis cliquez sur l’icône partager lorsqu’elle s’affiche.
1. Indiquez si vous partagez le fragment de code avec d’autres organisations, équipes ou utilisateurs.
1. Cliquez sur **Suivant**.
1. Sélectionnez l’organisation ou l’équipe avec laquelle vous souhaitez partager le fragment de code ou saisissez l’ID utilisateur de l’utilisateur avec lequel vous souhaitez partager le fragment de code.
1. Cliquez sur **Partager**.

Les fragments de code qui sont partagés avec vous s’affichent dans l’onglet **Partagés avec moi** du panneau Fragments de code.

## Importation et exportation de fragments de code

Vous pouvez exporter un fragment de code dans un fichier JSON et l’importer dans un autre scénario ou environnement.

1. Cliquez sur l’icône **Fragments de code** ![Fragments de code](assets/snippets-icon.png) dans la zone Contrôles.
1. Pointez sur le fragment de code que vous souhaitez partager, puis cliquez sur l’icône d’exportation lorsqu’elle s’affiche.
