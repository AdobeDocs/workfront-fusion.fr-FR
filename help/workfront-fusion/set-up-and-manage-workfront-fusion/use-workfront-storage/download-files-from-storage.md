# Télécharger des fichiers depuis le stockage

La zone de stockage Fusion vous permet de télécharger des fichiers à partir de votre stockage Adobe.

Pour une présentation du stockage, voir [Présentation du stockage](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

## Télécharger un fichier

1. Dans Workfront Fusion, cliquez sur **Stockage** dans le volet de navigation de gauche.
1. Accédez au référentiel et au dossier contenant le fichier à télécharger.
1. Sélectionnez un fichier en cliquant dessus dans le tableau.
1. Dans la barre d’actions qui s’affiche, cliquez sur **Télécharger**.

Une bannière de **progression** s’affiche en haut à droite et indique :

* Nom du fichier
* Pourcentage de progression du téléchargement
* Octets transférés
* Un bouton **Annuler** pour abandonner le téléchargement.

Le fichier est enregistré à l’emplacement de téléchargement par défaut du navigateur.

## Télécharger une version spécifique d’un fichier

1. Dans Workfront Fusion, cliquez sur **Stockage** dans le volet de navigation de gauche.
1. Accédez au référentiel et au dossier contenant le fichier à télécharger.
1. Sélectionnez un fichier et cliquez sur **« Versions »** dans la barre d’actions.
1. Dans le panneau **Historique des versions**, cliquez sur **Télécharger** en regard de la version à télécharger.

En cas d’échec du téléchargement, une notification toast s’affiche : *« Échec du téléchargement — Le fichier n’a pas pu être téléchargé. Veuillez réessayer.«*

Pour plus d&#39;informations sur les versions de fichiers, voir [Afficher l&#39;historique des versions de fichiers dans Storage](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/view-storage-file-version-history.md).
