# Charger les fichiers vers le stockage

Vous pouvez télécharger un fichier vers l’espace de stockage Adobe depuis Workfront Fusion à l’aide de la zone de stockage .

Le téléchargement est disponible lorsque vous naviguez dans un dossier (et non dans la liste des dossiers de niveau supérieur).

* Pour une présentation du stockage, voir [Présentation du stockage](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).
* Pour obtenir des instructions sur la création d’un scénario de chargement, voir [Création de scénarios à partir du stockage](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/create-scenarios-from-storage.md).


## Charger un fichier

1. Dans Workfront Fusion, cliquez sur **Stockage** dans le volet de navigation de gauche.
1. Accédez au référentiel et au dossier dans lesquels vous souhaitez charger un fichier.
1. Cliquez sur le bouton déroulant **« Charger le fichier »**
1. Sélectionnez **« Charger le fichier »** pour effectuer directement le chargement.

   Un sélecteur de fichiers s’ouvre.
1. Sélectionnez le fichier à charger.

   Une bannière de **progression** s’affiche en haut à droite et indique :

   * Nom du fichier
   * Pourcentage de progression du chargement
   * Octets transférés
   * Un bouton **Annuler** pour arrêter le chargement

Après le chargement, le fichier apparaît dans la liste des dossiers. La colonne **Taille** peut temporairement afficher *« Traitement... »* pendant que le stockage Adobe traite le fichier sur le serveur principal. La taille réelle du fichier s’affiche une fois le traitement terminé. Vous pouvez le vérifier en actualisant la page.

## Limites de chargement

* Taille de fichier maximale : **5 Go**.
